What is HoloForge?

HoloForge is a computer vision program that lets you interact with your screen using your hands and face. We’re experimenting with what happens when a normal webcam becomes an interface instead of just a camera.

Interacting with digital things using nothing but a camera, your hands, and your face. It tracks your movements in real time and turns them into interactions on screen.

How does HoloForge Work?

HoloForge is a project that uses computer vision to interpret hand and facial movements and use those movements to control different effects. The program uses real time camera feed to locate the user’s hands and fingers as well as their face. After identifying those, it determines what actions are being performed and takes corresponding actions.

The process can generally be broken down to: Identify (using the camera) Track (hands/face) Determine Action Render Effect and more Specifics about Framework are mentioned below.

Using the camera, movements and actions can be interpreted and effects can be rendered. In the program, the energy orb can be moved to where ever the user moves their hands. Users can charge the orb, fire the orb, or create web and other effect using gestures. HoloForge uses tracking points and HUD to provide real time feedback to the user. This, along with other effects, gives a futuristic feeling to the program.

A major idea behind HoloForge is to provide a more natural and more fun way to interact with a computer. This program tries to achieve this by using real time hand and facial movements to control various effects.

The Framework

Google MediaPipe is an open-source, cross-platform framework designed for building low-latency, real-time multimedia perception pipelines using on-device machine learning. It allows developers to deploy high-performance computer vision, audio, and text models natively on Android, iOS, Web (via WebAssembly), Desktop, and IoT hardware without relying on cloud processing.

Core Architecture & ConceptMediaPipe differs from traditional ML frameworks by structuring data processing as a directed acyclic graph (DAG).Calculators (Nodes): The fundamental building blocks of a pipeline. Each calculator is written in C++ and performs a specific task (e.g., resizing an image, running a TensorFlow Lite inference, or rendering a bounding box).Streams & Packets: Data flows through the graph via streams as immutable objects called "packets," tagged with precise timestamps to guarantee strict synchronization between time-series data like audio and video.Detection vs. Tracking Decoupling: To maximize efficiency, MediaPipe separates heavy detection models from lightweight tracking algorithms. For example, in hand tracking, it triggers a palm detector only when necessary; subsequent frames are followed by a faster tracking model until confidence drops, minimizing CPU/GPU drain.

The MediaPipe Solutions SuiteThe modern ecosystem is split into a streamlined, low-code product tier:ComponentDescriptionMediaPipe TasksUnified, cross-platform APIs that allow developers to integrate ML features into an app using as little as five lines of code.MediaPipe ModelsPre-trained, production-ready models deployed on top of TensorFlow Lite.MediaPipe Model MakerA low-code tool that uses transfer learning to let developers customize existing models using their own datasets.MediaPipe StudioA browser-based web application used to quickly prototype, benchmark, and evaluate models visually.

Supported Modalities & Key SolutionsWhile originally renowned for vision perception, MediaPipe supports three primary domains:Vision:Pose Landmarker: Track 33 human body joints in 2.5D space for fitness and movement apps.Face Mesh / Landmarker: Map 468+ 3D facial landmarks and blendshape scores for AR face filters and virtual avatars.Hand Tracking: Track 21 3D landmarks per hand for touchless gesture controls.Image & Object Tracking: High-speed detection and segmentation (e.g., background blur).Text: On-device language detection, text classification, and local Large Language Model (LLM) inference tasks.Audio: Real-time audio classification and sound event detection.

Technical Performance & BenefitsHardware Acceleration: Out-of-the-box support for CPU, GPU, and TPU acceleration (leveraging WebGL/WebGPU for browsers and Metal/OpenGL for mobile devices).Strict Edge Privacy: Because all image, video, and audio data are processed locally on the host device, user data never leaves the system.Efficiency: Built to run smoothly at 30+ frames per second even on computationally restricted hardware like mobile phones and Raspberry Pi single-board computers.Are you planning to deploy MediaPipe on a specific platform like Web, Android, or iOS, or are you looking to build a custom pipeline in C++?
